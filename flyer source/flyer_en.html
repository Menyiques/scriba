Native ASM

Your adventure runs on a native Z80 machine-code engine. Since 3.0, every machine is built from the same engine, compiled in pure Python.

  • AY music, FX and digitised WAV sound
  • On the Next, Layer 2 and the ROM left untouched
  • A memory budget with every export

Condacts in BASIC

If you have written BASIC, you can already write condacts: ON, IF, THEN, ELSE, LET and PRINT, with variables and timers.

REM El Faro
ON DIG SAND
  IF AT @beach THEN
    LET _SAND_DUG = 1
    CREATE #key @beach
    PRINT "A key peeks out."
  ENDIF
ENDON

What's newin this version
  1. MSX2. MegaROM cartridge, SCREEN 5 at 42 columns and music through the PSG.
  2. Amstrad PCW. Self-booting disk for the 8256 and 8512, at 90×32.
  3. Native Z80 engine on every machine. Goodbye, Boriel.
  4. CPC in Mode 1. 40 columns and 4-colour images in ZX0.
  5. 128K and Next. Text, music and FX in memory banks.
  6. Windows. A single encrypted .exe with the game inside.
  7. DAAD import. Opens DAAD 1 and 2 .ddb games (8-bit) and converts them to YAML, logic included.
