  • Música AY, efectes FX i so WAV digitalitzat

Condacts en BASIC

Si has escrit BASIC, ja saps escriure condacts: ON, IF, THEN, ELSE, LET i PRINT, amb variables i temporitzadors.

REM El Faro
ON CAVAR SORRA
  IF AT @platja THEN
    LET _SORRA_CAVADA = 1
    CREATE #clau @platja
    PRINT "Treu el cap una clau."
  ENDIF
ENDON
